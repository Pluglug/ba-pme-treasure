# PME hotkey conflicts

The hotkey checklist formerly kept here is now part of [[Guides/routes/solve-a-problem|Troubleshooting PME]], where it sits beside the matching context, keymap, and recovery answers.

Start with the shortcut symptom there. It asks you to check:

- the exact editor and mode;
- another Blender keymap item using the same key;
- the PME keymap scope;
- an operator call, report, or error logged in the Info editor or System Console.

A Poll controls whether a PME item is available after the shortcut reaches it. The keymap scope helps Blender decide where that shortcut is received.
