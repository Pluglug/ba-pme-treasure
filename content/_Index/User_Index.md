# People behind the PME answers

The forum archive is more useful when you can follow the people who built PME, tested it in daily work, and helped other users turn ideas into working menus.

## A few good trails to follow

- [[Users/roaoao|roaoao]] created Pie Menu Editor and answered questions across its editors, scripting helpers, and Blender integration. Start with [[Posts/2016/post_00001|the original PME announcement]] or the two-action [[Guides/showcases/name-objects-while-creating-them|create-and-name workflow]].
- [[Users/Pluglug|Pluglug]] maintains PME-F and has shared examples that connect PME to animation controls and Blender API discovery. See the [[Guides/showcases/transform-preset-control-surface|Transform Preset]] and [[Guides/showcases/context-browser-for-pme-scripting|Context Browser customization]].
- [[Users/Motiomancer|Motiomancer]] repeatedly turned workflow questions into working Sticky Key, sculpting, and Custom-layout examples. Follow the eight-part [[Guides/trails/from-shortcuts-to-workflow-tools|shortcuts-to-workflow-tools trail]].
- [[Users/MickHanks|MickHanks]] brought concrete workflow annoyances and experiments to the thread, including naming objects at creation and suggesting a collapsible window for emboo2's 42-button Popup Dialog. Start with [[Guides/showcases/name-objects-while-creating-them|Name objects while creating them]].
- [[Users/StroBlend|StroBlend]] shared practical panel-extension, row-layout, and custom-icon answers. The [[Guides/showcases/modifier-preset-shelf|Modifier preset shelf]] preserves one complete exchange.
- [[Users/Way2Close|Way2Close]] demonstrated a horizontal Panel Group toolbar that kept selection controls separate from the panels it opened. See [[Guides/how-to/build-stable-panel-group-toolbar|Build a stable Panel Group toolbar]].
