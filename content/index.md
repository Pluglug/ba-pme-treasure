# PME Community Knowledge Base

## What is PME?

**Pie Menu Editor (PME)** is a powerful Blender addon that lets you customize Blender's interface through:

- **Pie Menus** - Radial menus triggered by hotkeys
- **Popup Dialogs** - Custom dialog windows
- **Macros** - Chain multiple operations
- **Panel Groups** - Organize sidebar panels
- **Stack Keys** - Multiple commands on one key
- **Sticky Keys** - Hold-to-activate menus
- **Modal Operators** - Interactive tools
- **Property Editor** - Custom properties
