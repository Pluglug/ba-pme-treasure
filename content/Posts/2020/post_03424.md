[@roaoao](</u/roaoao>) I was wondering if there are any plans to support key-chords as a shortcut system in PME or if something similar already exists?

Key-chords allow for a much wider mapping of functionality to keys and they also vastly expand the number of possible shortcuts. They have been around for a long time, particularly in text editing software. The main idea is to press a key combination to activate a mini shortcut context and follow that with another combination to execute functionality.

This is nicely implemented in [VSCode](<https://code.visualstudio.com/docs/getstarted/keybindings#_keyboard-rules>). For instance, pressing `Ctrl+K` and then `M` allows for changing the language. But you can also use `M` by itself, or map another functionality to `Ctrl+G, M`.

I just wanted to run the idea by you, see if there are any plans for it, or if it’s already possible. Thank you for your great addon.
