[@Pinhead](</u/pinhead>), [@StroBlend](</u/stroblend>),  
Here is a [patch](</uploads/short-url/gswj0riw7nDQwXgQfPb5wW7zXrz.zip>) for PME 1.17.1. Extract files to `scripts/addons/pie_menu_editor` folder and restart Blender.

![](https://blenderartists.org/user_avatar/blenderartists.org/pinhead/48/528486_2.png) Pinhead:

> It is possible to make space beetwin menus wilder?

Added an `Extra Pie Slot Gap Size` option in `PME Preferences -> Settings -> Pie Menu`

![](https://blenderartists.org/letter_avatar_proxy/v4/letter/s/87869e/48.png) StroBlend:

> Idea/suggestion: have you ever think about creating an operator that could draw the pie menu editor in a panel ?

Added a panel in 3DView’s N-panel. By default it’s hidden. You can enable it in `PME Preferences -> Settings -> General -> Show PME Preferences in 3DView`
