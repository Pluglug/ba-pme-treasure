I was cheering loudly when i found a backup PME had made… but was a bit stumped when it only included 1 empty pie-menu… I have this feature ticked in PME but never really thought about it… unitl now…  
What is it PME backs up really?

It would be nice with a feature in “General settings” in PME to set a backup data-path pointing somehwere outside the Roaming folder where PME is installed, that is excluded whan updating PME so it won’t delete any backups or menus created, and also ( if it’s not just a glitch in this case ) PME makes backup’s of all menus.

From now on i will be extra careful, this was a painful experience
