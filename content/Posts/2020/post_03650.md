> I would really like to create a tool that combines Clear Location, Clear Rotation and Clear Scale as one command with checkboxes to be able to toggle them, just like Apply Object Transform has:  
>  ![image](https://blenderartists.org/uploads/default/original/4X/d/1/0/d10e54e56136c73553c82dbb861c1bf370180114.png)

You can create a modal operator for this tool. Here is [an example](</uploads/short-url/k3DhPSZVDMQHGavkOcZI15HoLE7.json>).  
Import .json file, call macro and use `1, 2, 3` keys to toggle location, rotation and scale options.  
I recommend to disable `PME > Settings > Modal Operator > Checkbox` option.
