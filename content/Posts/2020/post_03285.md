I didn’t know I needed this, thanks Roaoao.

you put the code in the custom tab and the name of your addon as the name

[![image](https://blenderartists.org/uploads/default/optimized/4X/9/6/8/96839ca9548ca413f78dc477e79dc532790ea1b6_2_690x65.png)image912×87 12.3 KB](<https://blenderartists.org/uploads/default/original/4X/9/6/8/96839ca9548ca413f78dc477e79dc532790ea1b6.png> "image")

to know the name that you need to put there you have to have active Python Tooltips in Preferences, Interface, Display

[![image](https://blenderartists.org/uploads/default/optimized/4X/a/6/4/a647279b237db5decc9c80729a1ecb80a4e6b01c_2_690x128.png)image828×154 16.9 KB](<https://blenderartists.org/uploads/default/original/4X/a/6/4/a647279b237db5decc9c80729a1ecb80a4e6b01c.png> "image")

then go to the addon tab and hover over the addon checkbox

![image](https://blenderartists.org/uploads/default/original/4X/a/1/a/a1aa5b5ee1b8d909cc2fcb27399431d9e8156cda.png)

you put in the name the part that is in quotes, in this case it was “softMod_addon”

Hope it helps
