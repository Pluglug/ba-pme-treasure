Hi roaoao!  
Is it possible to “call” a Pie Menu by mode and Window (Image Editor / Paint Mode), when the same key (TAB) is linked?

[![Scene](https://blenderartists.org/uploads/default/optimized/4X/b/f/3/bf34ede7f828d3098ec49256a92888a0382f2595_2_690x388.jpeg)Scene1920×1080 324 KB](<https://blenderartists.org/uploads/default/original/4X/b/f/3/bf34ede7f828d3098ec49256a92888a0382f2595.jpeg> "Scene")

  * With the (TAB) key in the 3D Viewport / Texture Paint Window, call up the menu:  
TAB - [Texture Paint]

  * With the (TAB) key in the Image Editor / View Window, call up the menu:  
TAB - [Image Editor] - [View]

  * With the (TAB) key in the Image Editor / Paint Window, call up the menu:  
TAB - [Image Editor] - [Paint]

  * With the (TAB) key in the Image Editor / Mask window, call up the menu:  
TAB - [Image Editor] - [Paint]
