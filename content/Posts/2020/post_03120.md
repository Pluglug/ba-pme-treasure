Thank you for the answer!  
I have also made the tool for vertex connect with PME which is really nice working for me.

[vertex_connect.json](</uploads/short-url/98sYBhY1KgbQbfITbaBheTAutIT.json>) (743 Bytes) - works only in vertex mode ( i use “w” in edge- and facemode for another macros)

  * select first vertex hover over last vertex and press “w”
  * or select two vertices and press “w”  

But i can’t cut with this tool from “vertex to edge” or from “edge to edge”. That would be nice of course if it would be possible with the same tool. Kind of knife+vertex connect tool in one tool.

I was looking for a way to speed up the knife tool because only with knife tool you can cut from vertex to edge,edge to edge etc… But with default knife you need 4 clicks!

  1. hotkey for call knife tool
  2. hover and select first position for a cut( place starting point)
  3. hover over second position and click ( place cut)
  4. confirm the cut with “spacebar”

What i was looking for is to create a cut tool where you can:

  1. hover over first position(vertex or edge) and press hotkey - knife tool start and places first vertex/starts the cut
  2. hover over last position(vertex or edge) and press same hotkey- cut to this place and confirms at the same time. Only 2 clicks!  
Over long modelling session it makes a lot of of time saving.

This is not possible in the moment because knife tool starts modal mode where you have to press predefined buttons.
