One option is to disable use frame in the popup menu on the pie menu, it separates each by the specific row but there is no overall frame.

![image](https://blenderartists.org/uploads/default/original/4X/e/e/b/eebe2f26e7ceb69ea913e69ae4dd7750ab7ae3c9.png)

[![image](https://blenderartists.org/uploads/default/original/4X/3/7/e/37e87f235a7ae93a276607a37d1073b5e526c36e.png)image558×586 37.8 KB](<https://blenderartists.org/uploads/default/original/4X/3/7/e/37e87f235a7ae93a276607a37d1073b5e526c36e.png> "image")

The other option is a lot more cumbersome but it gives each popup menu a frame:

[![image](https://blenderartists.org/uploads/default/original/4X/9/a/4/9a496f3df4c59e5208f655960b7f5556748d8422.png)image583×547 36.6 KB](<https://blenderartists.org/uploads/default/original/4X/9/a/4/9a496f3df4c59e5208f655960b7f5556748d8422.png> "image")

In the popup dialog that you’re using as container for the other popups you have to add the menus differently

go to the icon next to custom

![image](https://blenderartists.org/uploads/default/original/4X/2/e/9/2e9cace32d37376ffb71d4468eebec601da172df.png)

Press draw popup dialog

![image](https://blenderartists.org/uploads/default/original/4X/5/c/e/5ce05af4da1897a54a061bb97acbf6a48c10229f.png)

Add the specific popup menu

![image](https://blenderartists.org/uploads/default/original/4X/5/9/3/593cb123205ffebf3ed7d724f8de68bf1d5cc035.png)

you are gonna get `draw_menu("Your menu")`  
you have to add in the brackets, frame=True: `draw_menu("Your menu", frame=True)`

[![image](https://blenderartists.org/uploads/default/optimized/4X/0/1/9/019b66e5c272cb9918928a63c223e07f857d8d48_2_690x146.png)image718×152 11.8 KB](<https://blenderartists.org/uploads/default/original/4X/0/1/9/019b66e5c272cb9918928a63c223e07f857d8d48.png> "image")

and you should get the framed menus
