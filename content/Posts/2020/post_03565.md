> is it possible to pop up the Vertex Weights sub-panel at mouse cursor location with user defined hotkey?

Where can I find this sub-panel?  
In most cases you can use [Panel Tools](<https://imgur.com/bQso8Om>) a Stack Key with 1 slot.  
Add a new Stack Key, select it and press `PME Panel Tools > Add as Button to Stack Key > Command 1`.
