Hello **roaoao** , I have a question about “Macro Operator”.  
I’m trying to create a setup that will do the following things in order:

  1. Add Plane
  2. Display a custom menu on which I can resize the added plane
  3. Perform the Apply Scale operator.

Is there any technical possibility for the third step to be completed only when the dimensions of the plane are confirmed in the second step?
