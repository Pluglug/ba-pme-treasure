![](https://blenderartists.org/letter_avatar_proxy/v4/letter/j/e19adc/48.png) JustRon:

> Also, without using python, is it possible to save states for tools in a macro so they can be retrieved later? For example, save the current snap settings, change them to something different, do something else and apply the original settings again.

Check these two posts:

![](https://blenderartists.org/user_avatar/blenderartists.org/roaoao/48/37600_2.png) [Pie Menu Editor 1.18.7](<https://blenderartists.org/t/pie-menu-editor-1-17-5/662456/3100>) [Released Scripts and Themes](</c/coding/released-scripts-and-themes/50>)

> Yes, they will be lost after restart. If you want to save data in blend file add a new Property item and press Store in ... button in [advanced settings](<https://archive.blender.org/wiki/index.php/User:Raa/Addons/Pie_Menu_Editor/Editors/Property/#Storing_Values>). Select Scene for example. To access the data use this code: C.scene.MyProperty C.scene.MyProperty = "My Value" 

![](https://blenderartists.org/user_avatar/blenderartists.org/roaoao/48/37600_2.png) [Pie Menu Editor 1.18.7](<https://blenderartists.org/t/pie-menu-editor-1-17-5/662456/3098>) [Released Scripts and Themes](</c/coding/released-scripts-and-themes/50>)

> You can store your variables in pme.context.globals dict: pme.context.globals.get("my_var_name", "my_default_value") pme.context.globals.update(my_var_name="my_value")
