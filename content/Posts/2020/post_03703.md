## 💬 Content

Yes, with a popup menu made with others popup menus inside

For example:

  1. Make a popup dialog menu with the items on the left menu
  2. Make another popup dialog menu with the items on the right menu
  3. Make another popup dialog menu and put both menus together
  4. Put that last one on the top pie menu

Personally at first I did that, but menus work in a way that you can only perform 1 action so the best is just to call the full popup dialog with the options you want.
