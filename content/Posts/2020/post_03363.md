> Is it possible to add uv live unwrap as a property in a pie menu?

Hi [@eltarbos](</u/eltarbos>),

Yes, select the pie menu, open `UV` menu, move the mouse over `Live Unwrap` button and press `RMB - Pie Menu Editor - Add to ... - Property`

Or use this code in `Property` tab:
    
    
    C.scene.tool_settings.use_edge_path_live_unwrap
