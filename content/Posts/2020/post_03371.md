you should check out [PolyQuilt](<https://blenderartists.org/t/polyquilt-addon-for-blender-2-8/1168918>) addon, it has some of the hold LMB to do something feature like you said.

I would suggest set hotkey for those insert loop cut, bevel, extrude to mouse keyboard combination. personally I set ctrl + mouse wheel up to inset loop cuts, ctrl + mouse wheel down to bevel etc.  
the modeling flow is a lot faster than the 2 sec wait you asked.
