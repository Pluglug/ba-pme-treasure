![](https://blenderartists.org/user_avatar/blenderartists.org/nanomanpro/48/18745_2.png) Nanomanpro:

> Is there a parameter that will keep the window at the top all the time?

Blender doesn’t support this. Check your window manager features. You can rules for windows in some of them.

![](https://blenderartists.org/user_avatar/blenderartists.org/nanomanpro/48/18745_2.png) Nanomanpro:

> To close the window, I’m trying to use the same [module](<https://imgur.com/z5c87Lh>) but limited to the “Outliner” window, which performs the default keystroke shortcut for closing windows, “alt + f4”, but this solution does not work.

Unfortunately, we can’t close windows by using Blender API.  
Some other notes:

  * PME support only Blender hotkeys in `Hotkey` tab. That’s why `Alt+F4` doesn’t work.
  * You have 2 stack keys with 1 slot. But in most cases you need to use 1 stack key with 2 slots.
