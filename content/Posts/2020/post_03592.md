# Pie Menu Editor 1.17.5

* * *

### What’s New:

  * Blender 2.91 Support
  * Customizable number of menu list rows
  * New global variable for scripts to store user data:  
`U.foo = "value"` or `U.update(foo="value1", bar="value2")`  
`U.foo` or `U.get("foo", "default_value")`
  * Bug Fixes

### How to Update:

  * Backup your pie menus using `Export` button (optional).
  * Open `Edit > Preferences`.
  * Go to the `Add-Ons` tab.
  * Click `Install...` button, navigate to the file you downloaded and install it.
  * **Restart Blender.**
