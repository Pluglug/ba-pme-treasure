> Is it possible to make a macro to select all objects in a collection?

As [@Metin_Seven](</u/metin_seven>) [mentioned](<https://blenderartists.org/t/pie-menu-editor-1-17-1/662456/3253>) you don’t need a macro here. Try to use Select Grouped operator in `Command` tab:
    
    
    bpy.ops.object.select_grouped(extend=False, type='COLLECTION')
