In that case you can use the advance option poll

[![image](https://blenderartists.org/uploads/default/optimized/4X/4/0/7/407ec952851c039c19a800068fe4a54cb9777e88_2_690x118.png)image828×142 12.7 KB](<https://blenderartists.org/uploads/default/original/4X/4/0/7/407ec952851c039c19a800068fe4a54cb9777e88.png> "image")
    
    
    return C.mode== 'PAINT_TEXTURE'

Or if you only want the pie menu to trigger in the View3D space:
    
    
    return C.mode== 'PAINT_TEXTURE' and C.area.type == 'VIEW_3D'
