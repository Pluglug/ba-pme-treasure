2 options

1.- Press the gears for more options, now if you change the radius value you can have a custom one for that pie menu

![image](https://blenderartists.org/uploads/default/original/4X/f/6/e/f6e133bd016cc18ce0e956d6d30456d1021be2d9.png)

2.- You can add a separator in the specific spot, try to use this outside a framed menu since it will stretch the border

Create a button and use this `L.separator(factor=10)` in the custom tab to create a space with the size used in the factor

![image](https://blenderartists.org/uploads/default/original/4X/1/9/c/19cf847d243721412f0ef54047ef31ba75d0fb01.png)

In your case you could use this separator in the bottom of the top menu
