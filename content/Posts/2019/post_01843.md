![](https://blenderartists.org/user_avatar/blenderartists.org/frankieh/48/670768_2.png) FrankieH:

> is it possible for me to make a menu that activates a command when I release the hotkey without moving the mouse away from the center.

Yes, add a `Stack Key` for the “Center” command with the same keymap and hotkey. And use `Tweak` or `Hold` [hotkey mode](<https://en.blender.org/index.php/User:Raa/Addons/Pie_Menu_Editor#Hotkeys>) for the pie.
