## Pie Menu Editor 1.15.21

#### What’s New:

  * [Toggle-able menu slots](<https://i.imgur.com/uqgxz2V.mp4>)
  * [Adding existing menus to a pie, menu or popup](<https://i.imgur.com/rU3dGMA.mp4>)
  * Bug Fixes

#### How to Update

  * Backup your pie menus using _Export_ button.
  * Open _User Preferences_ (ctrl+alt+U).
  * Go to the _Add-Ons_ tab.
  * Click _Install Add-on from File_ button, navigate to the file you downloaded and install it.
  * **Restart Blender**.
