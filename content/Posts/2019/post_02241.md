just sharing,

I’ve got a bad habit NOT naming my object as I add them. This only leads to confusion later in the project. So I hacked away to add an object “cube” and it asked me to name it in the popup.

Made a script that makes a TOOLS PANEL that has a cube add button with a row prop to name that object. I ran that script so it registered. Then in PME attached that external script to a Popup Dialog. Messy yes, but works.

I learned much and hope to greatly refine to just Pie, Click, Name, done. Then I apply it to all my major Object Adds.
