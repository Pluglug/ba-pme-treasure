> is it possible to make the macro function ( pme ) will autorun a set of commands at startup or everytime you open or start blender

Blender autoruns python scripts from _[config](<https://docs.blender.org/manual/en/2.80/advanced/blender_directory_layout.html#platform-dependent-paths>)/scripts/startup/_ folder.  
PME has it’s own autorun folder - _[config](<https://docs.blender.org/manual/en/2.80/advanced/blender_directory_layout.html#platform-dependent-paths>)/scripts/addons/pie_menu_editor/scripts/autorun/_

Try to copy your scripts to one of these folders.
