> [@roaoao](</u/roaoao>), can you somehow pass an argument when launching external script?

Yes, you can pass them like this:
    
    
    execute_script("scripts/print.py", msg="My Message")
    

Use `msg` data in external scripts like this:
    
    
    print(kwargs["msg"])
