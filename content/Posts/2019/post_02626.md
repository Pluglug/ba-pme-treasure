Here’s an odd issue that I encountered. Apparently when having the PME installed in either Blender 2.80 or the latest builds of 2.81 it causes massive problems with the preferences editor.  
So far I only encountered this issue on windows though.  
[@roaoao](</u/roaoao>) let me know if you are able to reproduce this bug.

To demonstrate this I deleted my config, datafiles & scripts folder and saved new preferences & a startup file for the newly created config folder, to be sure that I have the factory settings.  
I copied the config folder, zipped it and installed it as a new application template. Afterwards I installed version 16.00 of PME. The same bug also appears with older versions like 15.23 but I haven’t tried any older versions than that.

After doing this when using any of the default templates it all runs fine but when using a custom one or even loading factory settings, the preferences editor becomes almost unresponsive and switching tabs won’t work anymore. If you scroll long enough, content from other tabs in the preferences appear.  
This all only happens when the PME is installed. It doesn’t even need to be enabled.
