> When calling a pop up from a pie (with expand checked), is there a way to adjust the width of the popup?

Yes, we can increase the width by using [scale_x](<https://docs.blender.org/api/blender2.8/bpy.types.UILayout.html#bpy.types.UILayout.scale_x>) property. Add a row with this code (`Custom` tab):
    
    
    L.scale_x = 5; L.scale_y = 0.00001; L.label(text=" ")
