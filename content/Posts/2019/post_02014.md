# Pie Menu Editor 1.15.17

* * *

### What’s New:

  * Blender 2.8 Beta Support
  * Bug Fixes

### How to Update:

  * Backup your pie menus using _Export_ button (optional).
  * Open _User Preferences_.
  * Go to the _Add-Ons_ tab.
  * Click _Install Add-on from File_ button, navigate to the file you downloaded and install it.
  * **Restart Blender.**
