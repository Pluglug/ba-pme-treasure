> would be possible to add a default lateral margin to pop-ups? attaching example.

Hi [@rhyging5](</u/rhyging5>),  
You can add a new popup dialog with 1 row and 3 buttons for this:  
1st and 3rd button (margins): `Custom` tab with `L.separator()` code  
2nd button: `Menu` tab with `POSE MENU` popup dialog (with `Expand Popup Dialog` enabled)
