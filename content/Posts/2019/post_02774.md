![2_auto_backups](https://blenderartists.org/uploads/default/original/4X/3/6/a/36abc784ce9ab3823975366267feb179d248e811.png)

### What’s New:

  * Blender 2.81 Support
  * Auto-backups (_pie_menu_editor/data/backup_ folder)
  * Bug fixes

### How to Update:

  * Backup your pie menus using _Export_ button (optional).
  * Open _User Preferences_ (ctrl+alt+U).
  * Go to the _Add-Ons_ tab.
  * Click _Install Add-on from File_ button, navigate to the file you downloaded and install it.
  * **Restart Blender.**
