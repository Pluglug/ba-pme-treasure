> is it possible to add to pie menus via right-clicking the breadcrumb menus (menu items which lead to further menu items)?

No, but I’ll add some tool for this.

In PME 1.15.20 you can copy Menu ID and use it in this code (`Custom` tab):
    
    
    L.menu(menu="MENU_ID")
