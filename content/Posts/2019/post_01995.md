> How to add a modifier (for example an array) to a modal operator, and change the count?

Hi, here is [Modal Subsurf Modifier](<https://blenderartists.org/uploads/default/original/4X/5/2/4/524d9c8730e7fc8b2a69a53ac2d018d6992b4250.json>) example ([video](<http://i.imgur.com/QX75d9n.gifv>)).  
Note that `Render Levels` sub-hotkey doesn’t redraw Properties area for some reason. That’s why we need to add `On Update` code to redraw it manually.

[Some info](<https://archive.blender.org/wiki/index.php/User:Raa/Addons/Pie_Menu_Editor/Editors/Modal_Operator/>) about modals in PME.
