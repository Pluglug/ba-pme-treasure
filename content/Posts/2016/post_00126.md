One of the pie menus has stopped working when I launch Blender this morning, it was working last night.

I’ve tried the the followings and none works.

  1. Restart blender.
  2. Replace it with backup, import option: replace if exists. Restart blender
  3. Reinstall PME and import backup, restart blender.

Interestingly _import backup with option: rename if exist_ restores the function, but only for the renamed one. If I was to remove the .001 in the name, it would stop working. It would works again if .001 is added back to the name.

All other pie menus work fine, just the Grab one is having some troubles.
