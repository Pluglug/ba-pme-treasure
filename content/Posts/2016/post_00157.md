> roaoao what is the difference between 3dview and 3d view generic

I’m not sure. I didn’t find any documentation about keymaps.

Afaik, the difference is in priority.  
In 3d view blender uses this priority list:

  * Screen Editing
  * Grease Pencil
  * Mesh, Object Mode, Pose, …
  * Object Non-modal
  * Frames
  * 3D View Generic
  * 3D View
  * Window
  * Screen

So if 3D View Generic and 3D View has the same hotkey, blender will use 3D View Generic’s hotkey.

Also 3D View Generic (and all other …Generic keymaps) is active when mouse is over any part of the view including tool panel (T), preferences panel (N) and a header.  
3D View is active only when mouse is over 3d region.
