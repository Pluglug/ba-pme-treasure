## 💬 Content

If you use a mouse button (e.g. middle mouse button) to rotate, move or scale the view and want to use it as a hotkey modifier, you should modify the hotkey:

  * Open user preferences (File - User Preferences - Input tab)
  * Search the hotkey by name - _rotate view_
  * And use _Tweak_ mode for that hotkey instead of _Mouse_ mode
