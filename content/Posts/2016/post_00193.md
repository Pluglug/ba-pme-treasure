> Nice. So pressing the same key more then once will toggle between two different menus, right?

No. Opened menus, dialogs and interactive commands (like Loop Cut) block the UI.  
All other commands should work. And you will be able to use them in your pies (eg if you select the same pie slot twice it will execute 2 different commands)
