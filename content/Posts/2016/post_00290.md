> hello roaoao, can help me about to the “Stroke Method” of sculpting? The command I got works fine, but just for a specific brush only. I would like a command that change to “line” or “anchored” method whatever the brush you are using. Thanks again for all support provided for each specific question ![:wink:](https://blenderartists.org/images/emoji/twitter/wink.png?v=12)

The python path for the current brush is **paint_settings(C).brush**. You can use it in Property, Command and Custom tabs.  
In your case you need to use this code in Command tab:

Line Stroke Method:
    
    
    paint_settings(C).brush.stroke_method = 'LINE'
    
    

Anchored Stroke Method:
    
    
    paint_settings(C).brush.stroke_method = 'ANCHORED'
