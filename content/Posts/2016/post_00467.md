I found a small bug when editing a pop up dialog:  
Add a column separator to a set of buttons. Start deleting buttons, leaving the buttons in the column for last. It will allow you to delete everything in the panel and occasionally crash blender. Sometimes there is just an empty/extra row left over but no buttons.

Normally there is a default ‘row’ left over, or it won’t let you delete the last button.  
If you remove the column separator before deleting buttons, its fine.
