> Hi. This add-on looks really useful, i have 2 questions thought.
> 
>   * I’ve read in this thread that 2 pies can’t share the same hotkey. Is it global or per-context? EG is it possible to use “q” to call one pie in object mode, and “q” to call a different pie in edit mode?
>   * Do pie menus created with this add-on work without the add-on? I’ve read you can’t export to python code so i fear they won’t but i would definitely feel safer if i my menus didn’t depend on some 3rd party tool that could (i sure hope not) stop working at some point (and i could disable the editor when i don’t need to -edit- a menu, less add-ons active, less chance for blender to crash)
> 

  1. It’s per-context. You can use Q hotkey to open different pies in different modes. You can even open different pies in one (eg object) mode. Here is an

.

  2. No, unfortunately. This add-on adds some features that blender doesn’t support by default.  
In the next version I’ll add another unique feature. It will allow to use hotkeys like: hold _Middle Mouse Button_ \- press _Right Mouse Button_ or hold _Left Mouse Button_ \- scroll _Mouse Wheel_ _._
