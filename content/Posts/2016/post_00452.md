Mighty Pea:

> I’m trying to set up this as a hotkey:
> 
> In object or edit mode, holding the key goes into sculpt mode and activates a brush preset (grab, for instance). Letting go of the key goes back to object or edit mode.
> 
> In sculpt mode, pressing the key only activates the brush preset. Ideally, pressing and holding it would activate it only for as long as the key was held, and afterwards it would go back to the previously select brush preset.
> 
> Is this (or something like it) possible?

You can use [sticky keys](<https://www.youtube.com/watch?v=pcFOPWnHC7U>) to temporarily change the brush.  
Unfortunately, you can’t change the mode (blender will crush) when the drawing/sculpting tool is active.
