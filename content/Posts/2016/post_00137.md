Great addon, congratulations again! Just bought it yesterday and after some playing around I found that if I use “Obj: Interaction Mode” (TAB Pie), in Hold button mode, if TAB is pressed (not held) on dupli group instance, it makes addon to crush. Only restarting blender is solution to restore functionality. It is true that it is nonsense to try to get into edit mode on dupli group but it may happen as an accident.
