**New features:**

  * Adding button’s command to pie menus using RMB context menu

  * Adding panels to popup dialogs in interactive mode
        

**Update instructions:**

  * Backup your pie menus using Export button. 
        

  * Open User Preferences (ctrl+alt+U). 
        

  * Go to the Add-Ons tab. 
        

  * Click 'Install from File' button, navigate to the file you downloaded and install it. 
        

  * Restart blender.
