I hacked out how to use the same header for more than on Editor.  
Sadly, you can’t just edit the first one to effect all others. This is a Copy not and instance, so editing the first header will not ripple onto the others.

Step 1.) Build the Header in any Editor you want.  
Step 2.) Go to a different editor and make a new header there.  
Step 3.) In PME list, double-click in Step#2 name to get into edit mode and copy that name.  
Step 4.) In PME list select step 1 Header you built and make a copy.  
Step 5.) In the PME list, double click Step#2 name to get into edit mode and Paste.  
So you made a header, then made a placeholder, then made a copy of the header you want to show in more than one place and renamed it.
