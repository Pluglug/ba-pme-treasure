It does seem like there’s a lack of support for all editors and discrete call-outs for certain ones, but there’s some things you can do.

Right click the editor type select in the top left corner of the editor and select PME at the bottom of the list, then put it on a pie as a property. It crashes blender for me if i try to put it in a popup dialogue with vertical menu inside a pie, but you can use a popup by itself and have the full set.

You could probably make a Modal where you press a key to go into it and then have different keys activate certain editors.

I haven’t figured out yet how to specify which editor changes though. It seems it only changes the one the cursor is over.

Make the editor a popup area with the commands>Popup Area>editors function. Basically what I was talking about doing in the post above. Currently can’t get it to scale the editor window properly though.
