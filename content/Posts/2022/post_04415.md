As far as activating that app only when Blender is started, I’d imagine that could be written into a shell script or other such OS app scripting tools. You’d probably want it to run if blender opens and only when it’s the focused app so it’s normal in other apps. Not finding any apps that will do single keys per app easily like hotkeys. [AutoHotkey](<https://www.autohotkey.com/>) should be able to do it.
