> how can i setup a key to be pressed twice? double click doesn’t seems to work in blender keymap editor

Double click works but it gets overrided if you are using another keymap with the same key on “Press”

If you want to do multiple things with the same hotkey you have to put them on Click/Double Click/Click Drag. Technically you can have 10 shortcuts with the same button if you count the 8 different click and drag directions
