Hello. I don’t know if anyone else ran into this issue, but thought I’d ask anyway.

Regarding the Advanced settings for an entry, selecting for it to be only invoked in a certain Mesh Select mode (Vertex, Edge or Face), or if only a certain object type is the Active object seems very picky and unreliable.  

[![image](https://blenderartists.org/uploads/default/optimized/4X/3/b/3/3b31c74036f02fa94f7e0dcf0051446d2a580030_2_690x272.png)image1050×415 56.4 KB](<https://blenderartists.org/uploads/default/original/4X/3/b/3/3b31c74036f02fa94f7e0dcf0051446d2a580030.png> "image")

  
Often when I set it up, it works, but after restarting Blender, it no longer works, even though I saved the preferences and the setting is still clearly there when I check it. It also tends to happen when importing entries with these settings in it.

To me it seems like the only way to make it actually remember these settings is to restart Blender, and without touching any other already existing entry in PME, create the entries I want to have these settings as new, add these settings, test them, save preferences, and quit Blender. If I do it this way, it usually finally stays working even after restarting/closing Blender.

Is there a known issue for these settings, or am I missing/misunderstanding something? At the moment I’m using Blender 3.1 and PME 1.18.5, but I had the exact same issue back on Blender 2.93 as well.
