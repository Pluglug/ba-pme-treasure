> Hi! is it possible to reproduce functionality of translate tweak hotkey with this addon?

Hi, yes, it’s possible using [Tweak hotkey mode](<https://wiki.blender.org/index.php/User:Raa/Addons/Pie_Menu_Editor#Hotkey_Mode>).  
Note that the add-on can’t override tweak hotkeys. So if Blender has the same tweak hotkey you need to disable it manually in user preferences (Input tab).
