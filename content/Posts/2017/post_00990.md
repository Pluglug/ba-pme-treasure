![](https://blenderartists.org/user_avatar/blenderartists.org/frankieh/48/670768_2.png) FrankieH:

> Is it possible to have something in the middle of a pie menu? For example I have put all the modes (object mode/edit mode/vertex paint etc) in a pie menu but want to have pressing tab quickly without moving the mouse to toggle between current mode and edit mode.

Yes, PME supports this behavior.  
You need to use [Tweek hotkey mode](<https://wiki.blender.org/index.php/User:Raa/Addons/Pie_Menu_Editor#Hotkey_Mode>) for the Tab hotkey. In this case the add-on will execute default Tab action (toggle edit/object mode) if you press it quickly.
