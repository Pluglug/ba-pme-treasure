> I’m wondering if it is possible to have nested buttons inside pie menu, like in this picture for example.

Yes, you need to create Popup Dialog for the nested button and use it in the pie menu’s slot ([Menu tab - Expand Popup Dialog](<https://wiki.blender.org/index.php/User:Raa/Addons/Pie_Menu_Editor/Editors/Popup_Dialog#Expand_Layout>)).
