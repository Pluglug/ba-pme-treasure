I really like “Stack keys”, could we have something similar that runs multiple commands one after each other?

I know we can do it by having many commands in the single line input separating with ;  
or having external scripts.

It’s just that the UI for Stack keys is really nice, I would like to have that UI but it executes each commands in order.

There’s even no need for a new menu type, it’s enough if the current command get’s that “add command” button and you can add and remove as many commands you want. Here’s a screenshot mockup.
