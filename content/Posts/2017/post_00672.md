> is it possible to make the menu appear when i only select a Lamp or camera ?

Yes, use __Object__ keymap and [poll method](<https://wiki.blender.org/uploads/e/ea/Pme1.13.0_adv_options.png>) (first yellow line) with this code:

Lamp:
    
    
    return C.active_object.type == 'LAMP'
    
    

Camera:
    
    
    return C.active_object.type == 'CAMERA'
    
    

Lamp and Camera:
    
    
    return C.active_object.type in ('LAMP', 'CAMERA')
    
    

You can find all object types [here](<https://docs.blender.org/api/blender_python_api_current/bpy.types.Object.html#bpy.types.Object.type>).
