> Anyone know how I can enable/disable pie menus depending on object/edit mode? I want to do some context sensitive pies…

In most cases you just need to [set/add the right keymap](<https://i.imgur.com/tWaiON7.mp4>) to create context sensitive menus. For example:  
**Object Mode** \- for object mode menus  
**Mesh** \- for mesh edit mode menus  
**Screen Editing** \- for global menus

To create complex context sensitive menus (eg. face/edge/vertex mode menus) you can use [poll method](<https://i.imgur.com/dGCdlwc.mp4>).
