![](https://blenderartists.org/user_avatar/blenderartists.org/anphung/48/39426_2.png) anphung:

> I’ve been wanting to change the X,Y,Z axis constraint hotkeys to three buttons next to each other. Can I do this with PME?  
>  I also want to change the translate, slide, rotate, and scale from G, GG, R, S to W, WW, E, R. I was able to change them in the UPref except the double tapping for Slide. Wonder if I could with PME.

Sorry for the late reply. I haven’t received a notification for some reason.

You don’t need any add-on for this.  
Go to User Preferences -> Input tab -> Transform Modal Map:

  1. Use _Add New_ button to add/change sub-hotkey for X,Y,Z axis constraint.
  2. Change _Translate_ sub-hotkey to W (for Slide tool).
