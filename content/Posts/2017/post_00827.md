[@roaoao](</u/roaoao>) I’m running into some difficulty organising my UI using the Panel Groups. For example I would like to hide the shading panel in the ‘n’ panel(The one with matcap and AO options). I would like this panel to be nestled away inside a button via a popup dialog. So I hide it from the ui and then add add the panel to a popup dialog. But the hide panel also hides it out of my popup dialog. It would be great if the hide panel had an option for where it hides the item from. That way users could hide a panel from the ‘n’ panel but add the panel to the ‘t’ panel. I’m not sure if this is possible but I think it would give an extra level of control when editing the UI. Either way, keep up the awesome work! Love the addon and I’m glad to see you ditch the Pie Menu Editor name as this addon is much more than just a pie menu editor! Hopefully the name change will attract more users ![:slight_smile:](https://blenderartists.org/images/emoji/twitter/slight_smile.png?v=5)
