> Would it be possible to add a small .png image to use as an icon on a button

If you browse to the pie menu editor folder there should be a folder called icons, you can put your own images there, mine are png at 64x64px (you could make it 32x32 if you have a lot and the loading time for the icons annoys you lol) then where you would normally add an icon through pme you can click custom and it should be there.
