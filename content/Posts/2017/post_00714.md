## 💬 Content

I don’t intend to use the popup with a hotkey. I want it to be visible in the pie menu when the context is correct, and hidden when the context is incorrect.

This mainly affect some custom command for different context.

When active object is a camera.  
![](https://blenderartists.org/uploads/default/original/4X/8/0/6/8061b1ae52bf078a82e124f3f304329d3b892bbb.png)  

When active object is not a camera.  

[![](https://blenderartists.org/uploads/default/optimized/4X/8/9/c/89c1a13e1ce4afbd4cb65d45fd598554a16c740e_2_690x304.png) Shot_557.png711×314 32.7 KB ](<https://blenderartists.org/uploads/default/original/4X/8/9/c/89c1a13e1ce4afbd4cb65d45fd598554a16c740e.png> "Shot_557.png")

  

As you see, the custom command buttons shows up even when the context object isn’t a camera. And it’s displayed in a weird position.

I was expecting the Poll Method to be able to resolve this by not displaying anything at all if context is incorrect.

Or better yet, it would be great to have a Panel Switcher, which given different conditions of the context, assigns different panels to be displayed.
