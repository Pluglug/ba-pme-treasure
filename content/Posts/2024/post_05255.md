## 💬 Content

Stack keys work for me in 4.2 here.

In that example are you switching transform pivot/orientation using multiple stack keys with one command, or a single stack key with multiple commands?

I’ve found that you need at least two slots in a stack key to make it display an overlay - with just one command it won’t display anything. Therefore toggling (or cycling) multiple command(s) in a stack key works.

A workaround if you have a stack key with only one command, is to just duplicate the slot - so there are two slots with the same command. It should display the overlay then.
