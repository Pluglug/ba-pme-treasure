TLDR: Problem was solved. For me it looks like in case when PME would try to open a popup window which cannot be opened (it doesnt exist or something) - some other items from menus/pie menus can dissapear until restart.  
In my case it was Show Overlay, and also some 'Popup DIalog" which also was a sector in pie menu. In case of popup dialog it doesnt dissapear entirely like Show Overlay settings, but after i try to open those popup dialog it only shows me the text with a name of those popup dialog, byt all buttons which should be there - dissapear.

Im always try to provide as much of reliable info as possible, but in this case it wasnt much of info.

Anyway i found what cause the issue.  
I was have another ‘regular menu’ where one of the menu item was lead to “Normals” panel added via 'Old Auto Smooth" addon. So when i click those item on menu, it open a popup panel with normals settings.

My old menu for this didnt work in 4.2, but it doesnt throw any error, just open a popup with a message what menu is lost (or something like that, i cant remember)  
But each time it open those empty popup, those pie with an Show Overlay - dissapear.

I was opening those menu because of muscle memory a few times, when remember what its no longer works in 4.2 and remind myself what i need to fix it, but forgot about this each time.
