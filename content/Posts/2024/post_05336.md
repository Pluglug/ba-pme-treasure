When Blender 4.2 came out, the [Extensions](<https://extensions.blender.org/>) program was released alongside it. This program requires a `blender_manifest.toml` file be present, but even if we don’t submit to the Extensions program anytime soon, the TOML file is meant to be a replacement standard for the `bl_info` variable which is now deprecated in 4.2+.
