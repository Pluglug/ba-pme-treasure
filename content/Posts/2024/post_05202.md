I use PME in 4.2 and have click drag set on many hotkeys with no issues.

Sometimes Blender’s keymap gets a little funky with multiple entries and ‘empty’ entries, maybe that has something to do with it.

Have you tried starting Blender from default and then install PME as the only addon?

  * Export your PME keys to a json file - use the ‘All Menus’ Option
  * Close blender
  * Rename the 4.2 folder to something like 4.2backup so Blender will start with defaults and no user addons/preferences loaded.
  * Then install PME and import the hotkeys.

That should tell you if the problem is with PME or not… Make a backup of the 4.2 folder while you’re at it. ![:slight_smile:](https://blenderartists.org/images/emoji/twitter/slight_smile.png?v=12)
