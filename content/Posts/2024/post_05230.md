Did you import settings from a previous environment when transitioning to 4.2?

One of the reasons I’m postponing my transition to 4.2 is the difficulty in migrating keymaps as expected. I thought it would be safer to rebuild from scratch rather than migrating settings from a previous environment, but I haven’t done it yet because it’s quite time-consuming.

Without going into too much detail, if my assumption is correct, the following method might work:

  1. Back up your menus and disable PME. If possible, disable all other add-ons as well.

  2. Search for “PME” in the Keymap settings and delete all “Call Menu (PME)” entries.

  3. Create a new keymap preset and use it from now on (`wm.keyconfig_preset_add`).

  4. Re-enable PME and check if the problem is resolved.

If you want to solve the problem cleanly, you could do a clean install of 4.2, refuse to import from previous environments, and import your menus as a .json file within PME. However, this approach would nullify any customizations made outside of PME. That’s why I’m ultimately planning to confine all my customizations within PME.
