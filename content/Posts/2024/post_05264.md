Hello, just sharing this tip since I remember seeing someone asking about this awhile back and I just now figured it out.

If you want a popup of PME preferences, there is the Popup Addon Preferences via PME, and you can pick Pie Menu Editor. However, I’ve always found it to be too small, and since it isn’t resizable, I end up digging in the User Preferences > Addons > PME. And that’s several extra clicks that add up over time.

_non-resizable Popup Addon Preferences_  

[![image](https://blenderartists.org/uploads/default/optimized/4X/e/c/b/ecbde8961ce1db1a338b12739c3206dd478529a6_2_690x244.jpeg)image1654×586 144 KB](<https://blenderartists.org/uploads/default/original/4X/e/c/b/ecbde8961ce1db1a338b12739c3206dd478529a6.jpeg> "image")

As an alternative, you can popup the addon like so:

_bpy.ops.preferences.addon_show(module=‘pie_menu_editor’)_  

[![image](https://blenderartists.org/uploads/default/optimized/4X/0/a/c/0acf0e1eb941426c79cfafec9d57cf8ef55ec892_2_690x239.png)image1672×580 50.1 KB](<https://blenderartists.org/uploads/default/original/4X/0/a/c/0acf0e1eb941426c79cfafec9d57cf8ef55ec892.png> "image")

And it pops up the User Preferences Menu, but with Addons, and Pie Menu Editor preferences already selected. No more extra clicks, and you can resize it.  

[![image](https://blenderartists.org/uploads/default/optimized/4X/a/5/5/a557a707b2adb3c7e70b94b3787bf454cf817a6c_2_690x430.jpeg)image1425×889 159 KB](<https://blenderartists.org/uploads/default/original/4X/a/5/5/a557a707b2adb3c7e70b94b3787bf454cf817a6c.jpeg> "image")

Maybe everyone knows this already, but I’ve been using PME for a long time and didn’t know about it, so it might help out someone.
