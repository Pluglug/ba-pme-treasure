Hey [@Pluglug](</u/pluglug>), When UVToolkit stopped receiving updates, I made a GitHub repository with the latest known version and began maintaining it as Blender updates came out. I also managed to get it submitted to the Extensions program with minimal friction.

Regarding your licensing concerns, any tool made for Blender is automatically GPL, regardless of if it has a price tag or not. In fact, paid add-on developers are _supposed_ to have their tools available for free “somewhere”.

Personally, I think having a public repo is the only good approach to keep PME maintained in the long-term. It’s a LOT easier to transfer ownership or have multiple owners of a GitHub project, not to mention forking as an option. Adding patches and relaying changes via this thread also probably isn’t the most concrete solution for more novice users.
