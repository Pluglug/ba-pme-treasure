By local do you mean local Transform Orientation? If so, a Stack Key with those two commands one after the other should work.

An easy way to set it up is to create the Stack key with two items (you’ll have to add the second one).  
In the 3dview set transform orientations to local, as well as Transform Pivot to Bounding Box.  
Then right click on each (there is a PME editor command at the bottom of the right-click pop up) and add them to the active stack key you just created.
