> How can I make this visible which button is active?

You can use _Enum Property_ to create a tab bar and _StackKey_ to store commands for buttons ([video](<https://i.imgur.com/GQvjl6a.mp4>)):

On Update slot:
    
    
    open_menu("Tab Bar Commands", props(menu))
    

Where _open_menu()_ function calls a slot from the stack key (_**Tab Bar Commands**_) by its name (**props(menu)**)
