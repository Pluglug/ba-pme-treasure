![](https://blenderartists.org/user_avatar/blenderartists.org/mesch973/48/1108407_2.png) MESCH973:

> it’s possible to insert this comand in the pie menu for enable the tweak mode?

Are you talking about [Tweak hotkeys](<https://wiki.blender.org/index.php/User:Raa/Addons/Pie_Menu_Editor#Hotkeys>)? Sure you can use them in PME (including keyboard tweak hotkeys) for pie menus without that _Realease Confirms_ option. Pie menus use that option by default when you release the hotkey while your mouse is over one of the pie’s slots.

![](https://blenderartists.org/letter_avatar_proxy/v4/letter/c/9fc29f/48.png) cet77:

> how to i get that to work with a pie menu that is already hardcoded in hardops? Say i wanted to open hardops pie, or maybe group-pro pie menu inside of my own pie?

You can use this code in Command tab:
    
    
    bpy.ops.wm.call_menu_pie(name="PIE_MENU_NAME")
    

Will add some user friendly tool to find Pie’s name in the next version (tomorrow).
