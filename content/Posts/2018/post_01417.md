> [@roaoao](</u/roaoao>) Would it be possible to split the screen (with set width or height) > change the editor type with 1 key/ button? For example, press button, 3D view is split from the right 300 pixels, editor type of the new view is changed to Outliner. Press button again, back to before.

Actually there is a tool for this in PME but it’s not finished yet ([video](<https://i.imgur.com/mm4qeUd.mp4>)):
    
    
    bpy.ops.pme.side_area(area='OUTLINER', side='LEFT')
    

The tool uses Toolbar’s Max Width as a width for the new area. Will add configurable width for the tool in the next version.
