**How to Update:**

  * Backup your pie menus using Export button (optional). 
        

  * Open User Preferences (ctrl+alt+U). 
        

  * Go to the <i>Add-Ons</i> tab. 
        

  * Click <i>Install Add-on from File</i> button, navigate to the file you downloaded and install it. 
        

  * <b>Restart blender. </b>
