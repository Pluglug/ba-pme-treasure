> With the new Property Editor, it’s possible to create a custom “toggle/ checkbox” button, right? Like, click, button is highlighted, click again, button back to normal.

Yes, you can use Boolean Property to create toggle-able buttons. In [this video](<https://youtu.be/xQ-ETd8xacA?t=93>) I’m using it to control 3 values at once (Grid Floor, Axis X and Axis Y).
