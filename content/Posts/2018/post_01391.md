![](https://blenderartists.org/user_avatar/blenderartists.org/draguu/48/15444_2.png) draguu:

> how do i add context wise properties ,  
>  like i want string prop for every object in scene , and so we can write different string for every object

Cool feature. Will add it in the next version.  
In the current version (PME 1.15.1) you can add a new StringProperty with these _Getter_ and _Setter_ slots:
    
    
    # Getter:
    return C.active_object.get(menu, "Default Value")
    # Setter:
    C.active_object[menu] = value
    

Where _menu_ is the name of the string property.

![](https://blenderartists.org/user_avatar/blenderartists.org/draguu/48/15444_2.png) draguu:

> how do i add conditions like , if bool prop is on , only then show this enum prop

You can do this in _Custom_ tab using [props()](<https://wiki.blender.org/index.php/User:Raa/Addons/Pie_Menu_Editor/Editors/Property#Scripting>) function:
    
    
    L.prop(props(), "MyEnum") if props("MyBool") else None
