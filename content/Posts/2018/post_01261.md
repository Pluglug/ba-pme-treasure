> I wanted to ask, is it possible to use PME to create a button that has several functions depending on which modifier key is held when pressing it? (ctrl shift alt)

Yes, you can store functions in Stack Key slots. And call them from the button using this code in Command tab ([video](<https://i.imgur.com/zYTc13Q.mp4>)):
    
    
    open_menu("Stack Key", event_mods(E))
    

Where _event_mods(E)_ function returns key modifier combination (e.g. _Ctrl+Shift_ , _Alt+OSKey_ , _None_).  
And _open_menu()_ function calls _Stack Key_ ’s slot by its name.
