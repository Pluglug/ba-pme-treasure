> Anyone know how to change BG color of popups?

[![](https://blenderartists.org/uploads/default/optimized/4X/6/c/b/6cb9a71a0c476cfd8fb14ee5ec6bc1fbb51de14f_2_690x262.PNG)Capture.PNG782×298 29.8 KB](<https://blenderartists.org/uploads/default/original/4X/6/c/b/6cb9a71a0c476cfd8fb14ee5ec6bc1fbb51de14f.PNG> "Capture.PNG")

  

Not sure if this is what you meant, but if it is, it’s called ‘Menu Back Inner’. It’s in the theme settings.  
File > User Preferences > Theme > Menu Back > Inner. ( It’s near the bottom. )

![](https://blenderartists.org/user_avatar/blenderartists.org/anphung/48/39426_2.png) anphung:

> Is it possible to draw the Redo Last(F6) panel elsewhere, in the N toolbar for example?

I don’t think the Redo Last F6 command or panel can be edited with PME because it is hard coded in Blender. ( There are a couple of panels like this. ) What I ended up doing was remapping my F6 to my right click menu to use it as a context menu.

Not sure if this is helpful but, good luck.
