> In sculpt mode, how can I increase/decrease the brush size, by let’s say 5px? I want to use shift + mousewheel for that.

Use _Stack Keys_ [to assign hotkeys to the code](<https://i.imgur.com/9BsnH8X.mp4>):
    
    
    brush(ups().use_unified_size).size += 5
    
    
    
    brush(ups().use_unified_size).size -= 5
    

Set _Sculpt_ keymap instead of _Image Paint_ (you can add both of them if you want by using **+** button)  
and _shift+WheelUp/WheelDown_ hotkeys instead of F1/F2.
