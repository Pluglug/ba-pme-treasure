![](https://blenderartists.org/user_avatar/blenderartists.org/toshicg/48/675666_2.png) ToshiCG:

> What does the “Keymap Names” value do? I thought it sets the context in which the menu will work and for the most part it seems to work that way.

Yes, it should work that way.

![](https://blenderartists.org/user_avatar/blenderartists.org/toshicg/48/675666_2.png) ToshiCG:

> However I’d like to have a pie that works when in Curve edit mode so I set the Keymap to Curve… but my menu doesn’t work. (It does work if I set keymap to 3d view or window) Why do you think that is?

Not sure. Maybe you modified the hotkey in Input tab.  
Input tab settings override PME’s settings.  
Find your pie’s hotkey in _User Preferences - Input tab - 3D View - Curve_. And press _Restore_ button if it’s visible.
