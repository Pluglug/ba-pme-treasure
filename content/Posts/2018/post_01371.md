## Pie Menu Editor 1.15.0

Lots of new features ~~and bugs~~ this time. So please don’t forget to backup your menus. And **DO NOT** update if you are in the middle of your project.

#### What’s New:

  * [Property Editor](<https://wiki.blender.org/index.php/User:Raa/Addons/Pie_Menu_Editor/Editors/Property>)
  * [Extending Panels](<https://wiki.blender.org/index.php/User:Raa/Addons/Pie_Menu_Editor/Panels#Extending_Panels>)
  * [Tag/Untag Group of Menus](<https://i.imgur.com/Hwrs49a.mp4>)
  * [Save/Restore Tree View State](<https://i.imgur.com/jKvxCLg.mp4>)
  * [Select Menu by Name or Hotkey](<https://i.imgur.com/bsaKFdq.mp4>)
  * [Auto-run Python Script Files](<https://wiki.blender.org/index.php/User:Raa/Addons/Pie_Menu_Editor/Scripting#Auto-run_Scripts>)
  * [Custom Global Functions](<https://wiki.blender.org/index.php/User:Raa/Addons/Pie_Menu_Editor/Scripting#Custom_Global_Functions>)
  * [New Global Variables: menu, slot](<https://wiki.blender.org/index.php/User:Raa/Addons/Pie_Menu_Editor/Scripting#Global_Variables>)
  * [New Function: props(name)](<https://wiki.blender.org/index.php/User:Raa/Addons/Pie_Menu_Editor/Scripting#Common_Functions>)
  * [Updated Function: open_menu(menu, slot, **kwargs)](<https://wiki.blender.org/index.php/User:Raa/Addons/Pie_Menu_Editor/Scripting#Command_Tab_Functions>)
  * Blender 2.8 Support

#### How to Update

  * Backup your pie menus using Export button.
  * Open User Preferences (ctrl+alt+U).
  * Go to the Add-Ons tab.
  * Click Install Add-on from File button, navigate to the file you downloaded and install it.
  * **Restart blender**.
