> What tools we will be able to create with this type of editor? Translate, rotate, scale? What else?  
>  I don’t want to add an editor just for 3 tools.

It would come in handy with any tool that has directionality. Translate/rotate/scale, certainly, but also: alignment tools, Gstretch and similar tools (that can be made only to work on certain axis). Extrude, with automatic selection of axis (I could set it up so (with e as a modifier key) e+lmb would extrude on the axis that most closely aligned with my mousepath, e+mmb would extrude on the _plane_ most closely aligned, and e+rmb would start a freeform extrusion.)

It’s something I’m used to from Voidworld, and I miss it almost every day ![:smiley:](https://blenderartists.org/images/emoji/twitter/smiley.png?v=12)
