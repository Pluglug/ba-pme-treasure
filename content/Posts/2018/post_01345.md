Mighty Pea:

> can I not force run the command regardless of location, or momentarily switch to the required mode, or trick it into thinking it is?

Yes, you can use some operators in any screen/area if you [override the context](<https://docs.blender.org/api/blender_python_api_current/bpy.ops.html#overriding-context>).  
For example:
    
    
    bpy.ops.console.clear(override_context('CONSOLE', "Scripting"))
    

Where _‘CONSOLE’_ is a type of the area and _“Scripting”_ is a screen name with that area.  
You can find more info about _override_context()_ function in _pie_menu_editor/scripts/autorun/functions.py_.
