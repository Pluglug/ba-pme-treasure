Dear [@roaoao](</u/roaoao>),

Hello. I hope this message finds you well.

The “Show only new menus” option has been an excellent feature that allows me to focus on creating specific functionalities. However, as the name suggests, it doesn’t help me when I reopen Blender.

To work around this, I’ve been organizing my created menus by assigning tags to each purpose or function. I’ve been enjoying creating menus by listing them using the “Group by Tag” in “tree_mode.”

But as the number of tags grows, this method becomes less comfortable.

One day, I noticed the “Filter by Tag” option. It was my savior, sweeping away my proliferating tags and giving me a tidy environment.

However, being a greedy human, I can’t help but ask for more from the “Filter by Tag”:

  * Three requests for the “Filter by Tag”

    1. When using “Filter by Tag” and changing the Menu name (`PMItem.label`), the menu disappears from the list. After editing the Menu name, I would like the filter to automatically update, so the item is not excluded from the filter results.

    2. When using “Filter by Tag” and duplicating an existing menu, the duplicated menu also disappears from the list. After duplicating the menu, I would like the filter to automatically update, so the duplicated item is not excluded from the filter results.

    3. When using “Filter by Tag” and adding a new menu, I would like an option to automatically assign the tag being referred to by “Filter by Tag” to the new menu.

Please note that manually reapplying the filter does provide the expected filter results, so this is a truly minor issue. If you ever find yourself with some spare time, I would be overjoyed if you could work on improving the “Filter by Tag” feature.

Please take care of yourself and thank you for creating such a fantastic add-on.

Warm regards,
