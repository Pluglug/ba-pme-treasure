Custom keymaps presets on blender are absolutely terrible specially if you use addons that create new keymaps. Its prone to duplication errors (addons) and if new native keymaps are added they might be lost between versions since your old saved preset doesn’t have it.

The only solution I found was saving your custom keymaps on the configuration file itself, so I have the default Blender Keymap with hundreds of changes saved in the config file.

Pretend the Import/Export function doesn’t exist
