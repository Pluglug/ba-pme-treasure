I don’t think it’s impossible.  
First, there are no themes in Pref>Themes that offer such an attribute.

However, Blender does have modules for drawing. In fact, ZenSets has successfully marked arbitrary vertices, edges, and faces.

While writing this, I realized there’s already an addon that provides this feature, and it’s free!  
[Poly Source Addon For Blender (gumroad.com)](<https://derksen.gumroad.com/l/polysource?layout=profile>)

Although you can’t change the line thickness, it allows for real-time marking, which I think is practical.
