Sorry for the lack of explanation! Also, I thought you could use it by typing it in the Property tab, but I was wrong, you need to use PME Property.  
Create a Property and configure it as shown in the following image.
    
    
    # Getter
    return bpy.context.active_object.color[3]
    # Setter
    bpy.context.active_object.color[3] = value
    

[![image](https://blenderartists.org/uploads/default/optimized/4X/d/1/7/d171b760f0d66475bdab1b5d0469ec656c1db2c4_2_636x500.png)image733×576 57.3 KB](<https://blenderartists.org/uploads/default/original/4X/d/1/7/d171b760f0d66475bdab1b5d0469ec656c1db2c4.png> "image")

Then in any menu item, call it using the Property name.  
![image](https://blenderartists.org/uploads/default/original/4X/3/f/8/3f8a1909c49f0332b461fdc4f2c5554f90a3c558.png)
