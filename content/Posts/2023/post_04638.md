Have you tried the “Poll Method”? If you want to limit yourself to some situation, you need to set up a poll instead of a key map. There is a preset that is just right for this purpose, and I have illustrated how to set it with an image. This field will work if you write a conditional expression that returns “True”, so you can also add a GPencil Draw Mode as I have shown in the Option. I hope this solves your problem.
