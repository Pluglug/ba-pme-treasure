So every time I want to remove a keymap from PME I need to burn my entire config folder and re-set up all plugins and key customisations? I don’t mind doing tedious things once-in-a-while if it’s something that lasts but this looks like a bug that will come back again. I don’t understand how it’s possible that these ghost keys are re-added even after PME has been removed.

This was started on a fresh 4.4 install so not really an upgrade situation unless there’s also issue importing previously saved PME settings. Blender has many issues with its keymap system but PME is the only addon I’ve seen do this: aggressively re-add removed key map settings.

Is there at least a way to prevent this from happening again?
