# PME-F v1.18.9 ![:pie:](https://blenderartists.org/images/emoji/twitter/pie.png?v=12)

Hey everyone! I’ve just released PME-F v1.18.9 with full Blender 4.5 compatibility!

**Key Fixes:**

  * **Side Area Toggle** : Now works properly with Blender 4.5’s drawing system and high-DPI displays
  * **Popup Area** : Size control functionality has been restored
  * **PME Toolbar** : Removed unnecessary memory access, no more bugs
  * **Panel Drawing** : Fixed panel attribute errors that were causing issues
  * **Icon Loading** : Eliminated TypeError spam when icons are missing (thanks to Furash!)
  * Plus various other bug fixes
