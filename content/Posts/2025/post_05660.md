# PME-F v1.19.1 ![:pie:](https://blenderartists.org/images/emoji/twitter/pie.png?v=12)

Hey everyone! I’ve just released PME-F v1.19.1 with Blender 5.0 support, bug fixes, and some small quality-of-life tweaks.

Most of this update is about stability and polishing existing features.  
Thanks to everyone who sent bug reports and feedback — it really helps a lot!

## Highlights

  * **More Stable CHORDS Menus**  
CHORDS mode is now more reliable, even when you trigger it quickly or repeatedly.  
If a chord times out, the regular PRESS menu will run instead, so your hotkeys feel more natural.

  * **Side Panels Behave Better**  
Top and bottom side areas now open and close more predictably, in line with the other side panels.

  * **Smoother Blender 5.0 Experience**  
Preferences and properties behave more reliably on Blender 5.0, reducing weird edge cases when restarting or switching files.

  * **Custom Icons & UI Polish**  
Custom icons are more robust across restarts and template changes, and a few rare crashes in the toolbar and panels have been cleaned up.

**Supported Versions:** Blender 3.6 ~ 5.0

## How to Update (Blender 4.2+)

### 1\. Remove old versions (required for this release)

If you previously added custom scripts or icons, back them up before removing:

  * addons/pie_menu_editor/scripts
  * addons/pie_menu_editor/scripts/autorun
  * addons/pie_menu_editor/icons

Then uninstall the old PME version from Preferences > Add-ons.

### 2\. Install the new version

  1. Back up your PME settings if needed using the **Export** button.
  2. Download the latest **.zip** file.
  3. Open Blender → **Edit > Preferences**.
  4. Go to **Add-ons** , click the **…** menu in the top-right → **Install from Disk…**.
  5. Select the downloaded **.zip** file and install it.
  6. **Restart Blender** (required).
