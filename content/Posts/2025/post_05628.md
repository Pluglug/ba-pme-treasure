# PME-F v1.19.0 ![:pie:](https://blenderartists.org/images/emoji/twitter/pie.png?v=12)

Hey everyone! I’ve just released PME-F v1.19.0 with full Blender 5.0 support!

Your support kept me going — thank you so much! Special thanks to [@atticus-lv](<https://github.com/atticus-lv>) for catching 5.0 issues early!

**Key Features:**

  * **JSON Compatibility** : Menu Enabled state now exported
  * **Experimental Feature** : New “Click” and “Click-Drag” hotkey modes
  * **Tag Filter Enhancements** : Tag Filter Synchronization and Quality-of-Life Option
  * **SideToggle Expansion** : Added TOP/BOTTOM alignment and vertical gap detection
  * **AreaOps Improvements** : Now recognizes third-party UI types automatically
  * **Blender 5.0 Ready** : Full compatibility with Python API changes  
See [PR #50](<https://github.com/Pluglug/pie-menu-editor-fork/pull/50>) for more details…

**Supported Versions:** Blender 3.6 ~ 5.0

**![:warning:](https://blenderartists.org/images/emoji/twitter/warning.png?v=12)Important:** Before migrating to Blender 5.0, **make sure to update your existing PME in Blender 4.5 or earlier and export your JSON**. This ensures Menu Enabled states are properly saved.
