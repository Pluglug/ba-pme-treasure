[@Pluglug](</u/pluglug>)  
I’ve found that PME doesn’t export the correct enabled/disabled state. The parameter in the json file doesn’t change when exported in either enabled or disabled state. When importing an exported json, they all import as enabled regardless of how they were exported.

[@Solum_Night](</u/solum_night>)  
Not sure if it will help at this point, but one way to work around the enabled/disabled issue is the tagging system (found in ‘Extra Tools’, the icon with three horizonal lines at the bottom of the column of icons in the middle of UI). PME will correctly remember all the tags when exporting, so you can set them in bulk after import.

  * Before exporting, Use Extra Tools>‘Tag Enabled Items’ to assign all enabled items to a tag called Enabled
  * Once they are imported, disable all of them using the ‘unchecked’ icon (which is below the ‘checked’ icon)
  * Then use the option ‘Enable by Tag’ and select Enabled - only the desired items will be enabled.
