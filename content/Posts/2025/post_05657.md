I think this very issue got fixed in the latest release:

![](https://blenderartists.org/user_avatar/blenderartists.org/pluglug/48/1028483_2.png) [Pie Menu Editor 1.18.8](<https://blenderartists.org/t/pie-menu-editor-1-18-8/662456/5652>) [Released Scripts and Themes](</c/coding/released-scripts-and-themes/50>)

> Release 1.19.1-beta.2 is now available. Please help test it on Blender 5.0. PME temporarily stores all internal states — settings, menu structures, commands — and restores them when switching sessions. Blender 5.0 changed core behavior, and this restore logic no longer works reliably, which means the entire add-on is affected. Since this whole concept is likely unnecessary in modern Blender, I simply disabled the restore feature. It works in my environment, but I need confirmation from yours…
