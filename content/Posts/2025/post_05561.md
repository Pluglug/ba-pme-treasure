Thank you for explaining this so well and providing a solution. I did not know about the extra auto-run scripts functionality.  
After thinking about this, I wonder how many users would appreciate a drop down box within PME settings which allows them to select the menus to load (and specify a default in the init.py) in a similar way to how Blender does with its hotkeys or theme settings i.e. we can place multiple settings files that Blender recognizes within a portable folder and figures out their absolute paths automatically.

In practice, this might even mean that users would be able to conveniently swap over PME menus on the fly to pull up different menus or functionality with the same hotkeys when they start working on different parts of a project instead of learning more shortcuts.
