In 1.18.8, the errors are simply hidden. A Type error occurs after execution, and the operator is just being cancelled. In my Fork, improper syntax properly throws errors. If you know the basics of Python, you would understand that your code is incorrect.

Please enable debug mode in PME 1.18.8 and check if it behaves the same way.

If you want to use that hack in PME-F as well, turn off Settings > Show Error Trace.
