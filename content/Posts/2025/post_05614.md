Yes, 5.0 support is in progress.

The Python API has breaking changes around property access, so it’s taking some time to work through everything.  
<https://developer.blender.org/docs/release_notes/5.0/python_api/#breaking-changes>

Big shoutout to @atticus-lv who caught these issues early and already submitted PRs ([#48](<https://github.com/Pluglug/pie-menu-editor-fork/pull/48>), [#49](<https://github.com/Pluglug/pie-menu-editor-fork/pull/49>))! Really appreciate the quick turnaround and contributions.
