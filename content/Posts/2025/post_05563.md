I agree. I also believe that even if this PME fork does nothing other than provide compatibility with future versions (and some bug fixes), it is worth supporting financially. The support/donation button on github requires an account though.

The old documentation was a bit tricky to follow initially, so I ended up watching some youtube tutorials which showcased the addon in a more practical way. I think if most Blender users understood how PME could help them work more efficiently, the sales would be 10x higher, and this community project would get much more funding too.
